🛃 帶回台灣要注意
  • 酒類每人 1.5 公升以內（年滿 18 歲）、捲菸 200 支以內（年滿 20 歲），入境行李總價值在新台幣 2 萬元內免稅，超過要申報（以海關公告為準）。
  • 肉類及肉製品（肉乾、肉鬆、含肉的泡麵與調理包）、水果、活體植物與種子，多半禁止或需檢疫，請先查農業部動植物防疫檢疫署的規定。
  • 液體、膏狀伴手禮與酒類要託運並包好；隨身行李的液體每瓶要在 100 毫升以內。
  • 刀具不能隨身登機；行動電源與鋰電池要放隨身行李，不能託運。
  • 退稅（如日本免稅、歐洲 VAT 退稅）制度會調整，要出示護照並保留單據，請依店家公告與當地最新規定為準。

⭐ Google 評分與評論（選填）
貼上你自己的 Google Maps 金鑰後，找地點、探索景點與餐廳（含 Google 星等、照片）、點到點交通時間都會改用 Google 地圖資料，位置會準很多。金鑰只存在這支手機的瀏覽器，不會被匯出或上傳。沒有金鑰也能用，但資料來自 OpenStreetMap，可能不夠準。
怎麼取得金鑰？（需要 Google Cloud 帳單帳戶）
  1. 到 console.cloud.google.com 建立專案並綁定付款方式。
  2. 在「API 和服務」啟用 Places API (New) 與 Routes API 兩個服務。
  3. 建立 API 金鑰；在限制裡選「網站」，填 https://yu-tinglu.github.io/* ，API 限制只選 Places API (New)。
  4. 把金鑰貼回這裡儲存。
Google 目前對每種服務有每月免費額度（找地點約 5,000 次、探索搜尋約 1,000 次、路線時間約 10,000 次，以 Google 價格頁為準），超過才收費。個人旅遊規劃通常用不到，但仍建議：①在 Google Cloud 設預算提醒；②到「配額」把每個 API 的每日上限調低（例如 50–100 次），就不會意外超額。
